# BuildScope — новый независимый веб-прототип

Это **новая реализация с нуля**, созданная по согласованным решениям из `docs/reboot`. **Не импортирует, не использует и не зависит от кода старого приложения** в корне репозитория.

## Запуск

Откройте `reboot-app/index.html` в браузере или запустите статический HTTP-сервер:

```bash
cd reboot-app
python3 -m http.server 8080
```

Затем откройте http://localhost:8080 .

Зависимостей и сборки нет: HTML/CSS/JavaScript.

## Что уже работает

- Тёмная главная с выбором станции через список и схематичную карту, фильтрами и переходом в рабочее пространство.
- Рабочее пространство станции: дерево конструкций и слоёв, выделение выбранного элемента в условной SVG-модели, режимы «Проект», «Факт», «Сравнение» (пока переключают подпись/режим, а не реальные инженерные данные), панель свойств.
- Работы: поиск, фильтр, план/факт/остаток, редактирование факта, добавление демонстрационной работы, сохранение локально в localStorage.
- Адаптивная компоновка.

## Ограничения

- **Демонстрационные** станции, карта, 3D-схема, проценты, даты и количества. География не соответствует реальным координатам, а геометрия не пригодна для инженерных расчётов.
- Нет сервера, пользователей, прав, базы, аудита, импорта документов, полноценного накопления по сменам и контроля редакций. localStorage **не является производственным хранилищем**.
- Редактирование факта в прототипе упрощено; перед реальной эксплуатацией необходимо реализовать `WorkActualRevision`, права координатора, историю и проверку единиц.
- Не подключать реальные строительные данные до реализации безопасности и резервирования.

## Сменный журнал (итерация 2)

- Отдельная вкладка **«Сменный журнал»**: дата начала смены, работа, фактическое количество, источник.
- Накопительный факт в разделе «Работы» теперь **вычисляется из сменных записей**, а не редактируется напрямую; общий план и остаток видны отдельно.
- Исправление факта требует причины, предыдущая редакция остаётся в локальной истории; повторное редактирование не суммирует старую и новую редакции.
- Экспорт JSON, сброс деможурнала, проверки синтаксиса и тесты `npm run check && npm test`.
- **Ограничения:** ещё нет выдачи нарядов, отдельных строк нарядов, согласования, прав, проверки дубликатов по исходному документу и серверного аудита. Журнал — интерактивный прототип, **не система для реального строительного учёта**.

Для просмотра на телефоне нужен доступный по сети статический хостинг; GitHub-ветка сама по себе не является публичным адресом приложения.
