# Рабочее пространство 0.9

Задача: инженер выбирает конструкцию в модели, проверяет происхождение количества и оформляет работу, не теряя пространственный контекст.

## План до реализации

Палитра: чертёжный синий #182832, стальная панель #203540, границы #354c58, светлый текст #e4edf0, спокойная бирюза #91cbc6, янтарь выделения #e1b56a. Светлая тема сохраняет ту же иерархию. Segoe UI для интерфейса, табличные цифры для количеств; без внешних шрифтов и декоративных изображений.

Компоновка: компактная строка проекта и файлов, выбор сборки, единая навигация режимов на всю ширину. В режиме модели слева дерево, в центре сцена с короткими инструментами, справа свойства или расчёт. Боковые панели сворачиваются. Ведомости и проверка используют широкое рабочее поле. Наряд сохраняет модель слева и редактор справа; на телефоне модель закреплена сверху редактора. Анимация занимает экран, пояснения свёрнуты.

```text
Проект / файлы
Сборка / вариант отметок
Модель | Наряд | Материалы | Армирование | Проверка | Источник
Дерево      Сцена / инструменты      Свойства
            Статус количеств
```

На телефоне режимы остаются сверху, дерево и свойства вызываются снизу; длинные инструменты не занимают сцену постоянно. Доступные действия имеют текст, а не только значки. Выделение, точные/условные количества и происхождение должны быть различимы без изучения меню.

Проверка плана: не превращать инструмент в обзорный дашборд с декоративными карточками и метриками. Центральный визуальный элемент — сама инженерная модель. Разделители показывают границы задач; подсветка показывает выбор. Персональные записи исходного наряда не переносятся.
