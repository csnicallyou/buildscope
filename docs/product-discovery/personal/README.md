# BuildScope Personal — рабочий инструмент одного координатора

**Статус:** концепция/интервью; ориентирован на применение до корпоративного внедрения.

## Назначение
Самостоятельно управлять работами нескольких объектов и подрядчиков без аккаунтов и действий других участников.

## Реальные источники информации
Устные сообщения, переписка, фотографии бумажных листов, Excel/таблицы, путевые листы. Наряды сейчас выдаются лично на бумаге либо таблицей.

## Модули для проектирования
- Карта объектов, левый список, сводки и статусы.
- Быстрый ручной сбор предложений подрядчиков на следующую смену, проверка/корректировка координатором.
- Таблица нарядов, печать нарядов по подрядчику, экспорт/отправка файла.
- Ввод факта с фотографии, посменные и накопительные объёмы; заявлено/проверено/неизвестно.
- Контроль выхода после начала смены, сводные трудовые единицы, персональный табель, фотографии двух подписей и ручная проверка.
- Учёт сторонней техники, госномеров, путевых листов и работ по участкам; формат путевого листа уточнить по образцу.
- Учёт материалов/заявок и проблем в пределах действий одного пользователя.
- Автоматическая генерация сообщения для группового чата с копированием.
- Связь с 3D при наличии модели, без обязательного связывания.

## Границы
Personal не требует регистрации подрядчиков, электронных подписей и корпоративного утверждения. Не следует делать фиктивные статусы «подрядчик подтвердил», если данные ввёл только координатор.

## Совместимость
Согласованные основные сущности и экспорт данных для будущего переноса в Platform; способ переноса определить позднее.

## Открыто
Приоритеты первой версии, необходимость локальной/облачной работы, форматы импорта Excel, сроки и способы резервного копирования.
