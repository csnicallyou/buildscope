# Журнал интервью и решений

Обновлено: 2026-11-17. Правило: после каждого ответа добавлять принятое решение, отдельно отмечать гипотезы и открытые вопросы; синхронизировать с `PRODUCT_DISCOVERY.md`.

| Вопрос/тема | Решение |
|---|---|
| Главный экран | Карта объектов + левый список |
| Рабочее пространство объекта | Настраиваемый старт, работа по объектам |
| Бумажные наряды | Печать по подрядчику; фото заполненного листа; ручной перенос |
| Цифровые отчёты | Параллельно ручному вводу, общая база |
| Редактор нарядов | Таблица + панель деталей |
| 3D | Двусторонняя связь наряд ↔ элемент, встроенный/полный просмотр |
| Объёмы | Посменно и накопительно; заявлено ≠ проверено |
| 13. Работники | В: сводные трудовые единицы + персональный табель |
| 14. Подписи | В: проверка листа целиком и индивидуально |
| 15. Начало/конец | А: две бумажные подписи, отдельное время |
| 16. Выход бригад | Б: фото после начала смены |
| 17–18. Техника | Сторонние машины, госномера, путевой лист, часы и конкретные участки; уровень детализации базы машин ещё открыт |

| 21. Как передают планы | **Г:** смешанно — мессенджеры, устно, таблицы/документы; нужен быстрый ручной ввод и фиксация источника |
| 20. Кто формирует наряды | **Б:** подрядчики сообщают планируемые работы, координатор составляет наряды; канал и согласование пока не уточнены |
| 19. Учёт техники по участкам | **Предварительно Б:** отдельные работы и часы по участкам; точный путевой лист пока неизвестен, пересмотреть по образцу |
