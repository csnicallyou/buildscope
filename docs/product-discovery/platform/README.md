# BuildScope Platform — корпоративная рабочая среда

**Статус:** концепция/интервью; не реализовывать без отдельной задачи.

## Назначение
Полноценная многопользовательская система для организации строительных работ на нескольких объектах. Не ограничивать функциональность нынешними бумажными процессами одного координатора.

## Целевые роли
Координатор, уполномоченный представитель подрядчика, руководство, инженеры, снабжение, диспетчер техники. Роли, права и ответственность требуют отдельного интервью.

## Модули для проектирования
- Объекты: карта, статусы, список, рабочее пространство объекта.
- Планирование: предложения подрядчиков, корректировка координатором, утверждённый наряд, цифровая выдача и подтверждение получения.
- Исполнение: смены, посменные факты, накопительные объёмы, проверка, проблемы.
- Персонал: сводные трудовые единицы, поимённый табель, время, бумажные/цифровые подтверждения с корректной юридической трактовкой.
- Техника: парк, сторонние заказы, госномера, путевые листы, часы по участкам, заявки, простои.
- Материалы: заявки, согласование координатором, снабжение, доставка, получение.
- Документы, коммуникации, уведомления, отчётность, история действий.
- 3D: элементы модели ↔ наряды/работы, свойства, размеры, объёмы и визуализация строительства.

## Принципы
Подрядчики могут работать непосредственно в системе; координатор видит происхождение данных и подтверждает факты. Сохранять план/заявлено/проверено/неизвестно. Проектировать полные цифровые процессы, не копировать ограничения бумажного документооборота.

## Открыто
Сценарий подтверждения наряда, права, юридически значимые подписи, маршруты согласования, состав MVP, техническая архитектура.
