## Ограничения

- Фактические проверки и облачные блокировки — в PROJECT_STATE.
- GitHub Actions первоначально не стартовал из-за оплаты/лимита аккаунта. Не менять биллинг.
- Объёмы AABB объединяются внутри элемента; между элементами пересечения не вычитаются. Площадь — поверхность, не опалубка.
- DXF — отдельная XY-проекция прямых сущностей, без пересчёта единиц, реконструкции и сохранения в JSON.
- Разрез без caps, замер без snap, временные виды не сохраняются, parentId не образует вложенное дерево.
- Автосохранения нет. Перед заменой проекта сохранить JSON.
- Python/IfcOpenShell пока отсутствуют; подключать только рабочим адаптером с fixture и проверками.
- minimatch override описан в DEVELOPMENT; не удалять без аудита и lint.

Проект можно продолжать через обычный Git/Node и подключённый GitHub без доступа к истории Codex.
