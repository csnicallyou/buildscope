## Важные исправления

Не возвращать DOM Html для подписей осей в Canvas без проверки частых переключений: ранее возникал removeChild с React 19. Native sprites устранили проблему. Материалы требуют обновления shader-флагов при переходе opaque/transparent; проверка видимости арматуры читает реальные пиксели Canvas, а не только чекбокс.

Основные ограничения: номинальные ФЛ/ФБС без заводской деталировки/подрезок, Лм1 и подготовка-схемы вне расчёта, необмеренные швы/обмазка по ведомости, раздельные координатные системы. Не приписывать геодезическую привязку условной выкладке каталога. Неподтверждённые числа не заполнять выдуманными значениями.
