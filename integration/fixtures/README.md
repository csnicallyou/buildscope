# Синтетический видеоролик

`synthetic-report.webm` — одна секунда программно сгенерированного тестового рисунка 160×120, VP8/WebM, без звука. Пользовательских фото, подписей, строительных документов и других исходных материалов в нём нет.

Рецепт генерации (только для пересоздания; для запуска тестов FFmpeg не нужен):

```text
ffmpeg -f lavfi -i testsrc=size=160x120:rate=10 -t 1 -c:v libvpx -b:v 80k -an synthetic-report.webm
```

Сценарий проверяет декодирование настоящего ролика в браузере, ограничение доступа и диапазонные GET-запросы. MediaRecorder в тестовом headless Chromium создавал контейнер без кадров, поэтому он не используется как источник проверки плеера.
