# JSON v1

```json
{
  "version": 1,
  "name": "Пример",
  "units": "m",
  "elements": [{
    "id": "element-1", "name": "Плита", "mark": "ПЛ-001",
    "category": "Плиты", "material": "Бетон В30", "color": "#aababc",
    "position": [0, 1.5, 0],
    "parts": [{"size": [2, 0.22, 5.8], "offset": [0, 0, 0]}],
    "source": "Условный пример", "confidence": "assumed",
    "parentId": null, "sourceRef": null
  }]
}
```

`position` — проектные координаты локальной системы элемента, `offset` — центр части относительно неё, `size` — размеры X/Y/Z, метры, Y вверх. Части образуют объединение; вырезы представляются разложением оставшегося тела на части. Координаты ограничены ±10 000 000 м, размер части не менее 0,000001 м.

`id` уникален в проекте, `mark` — маркировка. `category` группирует дерево. `material` — имя без отдельного справочника. `parentId` ссылается на элемент, сохраняется и проверяется, но пока не отображает вложенность. `sourceRef` — свободная ссылка на источник без автоматического открытия/сопоставления. Исходные строительные чертежи не коммитить.

| confidence | Значение |
| --- | --- |
| drawing | Из чертежа |
| computed | Вычислено |
| manual | Введено вручную |
| assumed | Предполагаемые / демонстрационные |
| unknown | Достоверность неизвестна |

Статус относится ко всей геометрии элемента. Все демо-данные — `assumed`. Объём, площадь полной поверхности и отметки вычисляются из геометрии и подписаны отдельно. Количество экземпляра — 1; повторяющиеся экземпляры имеют отдельные ID. Производные значения не дублируются в JSON, а пересчитываются.

**Неизвестные размеры нельзя заполнять выдуманными значениями.** V1 требует полную геометрию. Для неполных данных нужна новая схема с nullable-параметрами, статусами полей и поведением «геометрия отсутствует». `unknown` не разрешает выдумывать размеры.

Камера, тема, скрытие, изоляция, смещения, разборка и замеры — временное состояние, вне Project. DXF Drawing тоже отдельно и не сохраняется в v1. GLB экспортирует исходную модель с метаданными. CSV: строка на экземпляр, ID/марка/имя/материал/объём/площадь/количество/источник/достоверность; разделитель `;`, UTF-8 BOM, экранирование кавычек и префикс апострофа для потенциальных формул Excel.
