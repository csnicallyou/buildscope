# Формат инженерного проекта

Поддерживаются JSON v1 и v2. V1 остаётся читаемым и записывается как v1. Новые shape/evidence/document допускаются только в v2; изменения не выдаются за незаметную миграцию старого формата.

Базовые поля: version, name, units="m", elements. Элемент: id, name, mark, category, material, color, position:[X,Y,Z], parts, confidence, parentId, sourceRef. ID уникален; родители существуют и не образуют циклов. Y вверх, метры; координаты конечные в пределах ±10 000 000, размеры не менее 0,000001 м.

## Геометрия

Ровно один вид: непустые parts либо shape (при parts=[]).

- parts: массив {size:[X,Y,Z],offset:[X,Y,Z]}, объединение осевых параллелепипедов.
- shape.kind="extrusion": axis x/y/z, outline:[[u,v],...], depth. Для y профиль в X/Z, для x в Z/Y, для z в X/Y. Глубина симметрична относительно локального нуля. Контур простой, без самопересечений. Вырезы с открытой границей представлены невыпуклым контуром.
- shape.kind="solid": vertices:[[x,y,z],...], faces:[[i,j,k],...]. Замкнутая ориентированная треугольная оболочка.
- shape.kind="bar": diameter в метрах и points:[[x,y,z],...] — путь стержня.

Производные объём, площадь поверхности и габариты вычисляются и не дублируются как изменяемые инженерные поля. Вырез Фм2 учитывается по реальному П-профилю, а не по габаритам.

## Происхождение

confidence: drawing / computed / manual / assumed / unknown. V2 evidence содержит страницы PDF, лист, сборку, notes и representation:

| representation | Смысл | Количества |
|---|---|---|
|dimensioned|Геометрия по явно выбранным размерам|Вычисляются|
|nominal|Номинальное серийное изделие|Номинальные, включая их в итог нужно учитывать ограничения|
|diagram|Схема без утверждённой деталировки|Исключается из totals, в CSV пустые значения|
|envelope|Огибающая известного следа/габарита|Исключается из totals, в CSV пустые значения|

reportedVolume — отдельное число из спецификации, никогда не корректирует форму. reinforcement — строки исходной спецификации: позиция, название, сталь, диаметр в мм, count, length/totalLength в метрах, unitMass/totalMass в кг, страница, примечание. Неизвестные числа — null, не ноль. bars — отдельные пути визуальной схемы основной арматуры; каждый имеет ID, label, diameter в метрах, points. Схема не подменяет исходные cut lengths и не гарантирует изгиб/нахлёст.

## Документ

document хранит код, имя источника, число страниц, сборку, variant plan/sections, zeroAbsolute (146,35 для сооружений, null для каталога), сетку осей, реестр 25 листов с номерами страниц, issues, materials и дополнительные анкерные связи. materials — независимая ведомость; её нельзя прибавлять к геометрическим количествам. Полный разбор: docs/RECONSTRUCTION.md.

Неполностью известное тело без геометрии пока не поддерживается. Не выдумывать размеры ради обязательных полей: такую позицию сохранять в ведомости/реестре, а для произвольных неполных объектов проектировать новую версию схемы. Статусы отдельных параметров пока отсутствуют.

JSON/GLB сохраняют исходные положения, структуру, материалы и связи. Временные смещения, камера, видимость, замеры и локальный PDF не входят в JSON. parentId/sourceRef сохраняются, дерево пока группирует категории. CSV геометрии и CSV источника разделены; UTF-8 BOM, разделитель ;, кавычки экранируются, формулы Excel обезвреживаются апострофом.
