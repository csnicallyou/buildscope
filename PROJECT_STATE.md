# Состояние BuildScope

Дата: 2026-11-16. Этап: реконструкция предоставленного комплекта 10-25-М-КЖ1.5 завершена в пределах явно описанной геометрии и схем.

- Основа: main 05465eb. Рабочая ветка feat/drawing-reconstruction. Исходный PDF, растровые страницы и извлечённые тексты находятся только в игнорируемой drawings/review.
- Подготовлены павильон (168 элементов), навес (234 элемента; два варианта отметок) и отдельный каталог 22 гнутых деталей.
- Векторная раскладка: 102 ФБС + 27 ФЛ павильона; 103 ФБС + 31 ФЛ навеса. Повторяющиеся подписи и листы исключены по совпадению исходной геометрии.
- Добавлены Project v2 с сохранением v1, профили с вырезами, замкнутые тела, схемы стержней, происхождение/представление, ведомости источника, ссылки на страницы, реестр всех 25 листов и противоречий.
- В интерфейсе доступны схемы арматуры, вариант отметок по плану/разрезам, 3D-каталог, отдельные спецификации, просмотр локального PDF. Это предметная ручная реконструкция, не универсальный PDF-импорт.
- Проверено: typecheck, lint, 24 unit-теста, production build, все 9 E2E в Chromium, npm audit (0 уязвимостей). Осмотрены скриншоты павильона, навеса, каталога и прозрачного бетона со схемой арматуры. Готовы четыре JSON, GLB и пары CSV в output/projects. GLB проверены по magic/размеру бинарного контейнера. Сборка предупреждает о размере JS 1,43 МБ (gzip 405 КБ) и комментариях PURE внутри Zod.
- Известные ограничения: нижний профиль Лм1 и гнутые детали показаны схемой; огибающие подготовки исключены из расчёта. Полная изготовительная расстановка скоб/петель/нахлёстов не утверждена. ФЛ/ФБС имеют номинальные профили. Взаимная привязка двух объектов не задана.
- Достоверные геометрические количества отдельно от округлённых ведомостей. Фм2 и вырезы Пм2.2/2.3 считаются по профилю, не габаритам. Проверены объёмы Фм 54,231075 м³ и плит павильона 26,77826 м³.
- Источники и выбранные интерпретации: docs/RECONSTRUCTION.md и document.issues внутри JSON. Генератор: npm run export:projects; результаты output/projects.
- Следующие задачи: уточнить противоречия и профиль Лм1 по ответу проектировщика; затем отдельно изготовительная деталировка арматуры. См. HANDOFF. Vite не наблюдает output/drawings: на Windows запись скачанного GLB могла вызывать EBUSY в watcher.
