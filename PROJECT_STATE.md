- Источники и выбранные интерпретации: docs/RECONSTRUCTION.md и document.issues внутри JSON. Генератор: npm run export:projects; результаты output/projects.
- Следующие задачи: уточнить противоречия и профиль Лм1 по ответу проектировщика; затем отдельно изготовительная деталировка арматуры. См. HANDOFF. Vite не наблюдает output/drawings: на Windows запись скачанного GLB могла вызывать EBUSY в watcher.

## 0.4 — калькулятор выбранных объектов

В общем виде кнопка «Калькулятор» включает множественный выбор корней сборок. Клики по мешам/частям добавляют или убирают весь объект, в дереве есть флажки, все тела выбранных сборок подсвечиваются. Панель справа/ниже модели суммирует материалы по наименованию и единице; сталь в кг по спецификациям, анкеры в шт., геометрия в м³. Неопределённые строки не считаются нулём: известный объём + неизвестные позиции показываются вместе. Расчётные допущения и исключённые общие работы PDF обозначены явно.

calculator.ts разворачивает выбранные корни/дочерние ID в уникальные элементы, предотвращает двойной счёт. SelectionCalculator.tsx — UI, CSV с составом выбора/единицами/основаниями и защитой формул. «Добавить видимые» учитывает скрытие/изоляцию модели; камера и поиск в дереве не ограничивают объекты. Уже выбранные скрытые объекты остаются в расчёте с явной пометкой. Снятие отметки/крестик/очистка исключают их. Перезагрузка/смена проекта очищают временный набор, визуальный reset его сохраняет. JSON/геометрия не менялись, перегенерация модельных артефактов не требуется.

Проверено: typecheck, lint, 34 unit, production build и все 15 E2E. Новый E2E проверяет настоящие нажатия в WebGL, суммы двух Фм4, флажки/повторный выбор, скрытие/изоляцию, набор видимых, неизвестный щебень Фм2, CSV и телефон 390 px без переполнения. Повторное нажатие удаляет конкретную сборку. Открытие/закрытие панели не выключает накопление; отдельный вид остаётся одиночным. Геометрия/количества/JSON не менялись.
