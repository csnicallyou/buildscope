# Состояние BuildScope

Дата: 2026-11-16. Стадия: **локальный MVP 0.1 завершён**, проверен и интегрирован в main fast-forward.

- Последний проверенный кодовый checkpoint: `d99ce57` — feat: finalize verified Windows MVP and engineering handoff. Следующий коммит изменяет только документы состояния; его SHA смотрите через `git log -1 --oneline` (самоссылка на SHA собственного коммита невозможна).
- Текущая ветка: `main`. Ветка `feat/engineering-mvp` завершена на d99ce57, отправлена и интегрирована без переписывания истории. Для новой функции создать новую ветку от main.
- Приватный репозиторий: https://github.com/csnicallyou/buildscope. PRIVATE проверена через GitHub CLI.
- Реализованы параметрическая платформа, viewer, инспектор, управление отображением, замеры, точные количества объединений AABB, JSON v1, CSV, GLB и ограниченный импорт DXF в отдельный 2D-чертёж.
- Локально прошли воспроизводимый npm ci, npm audit (0 уязвимостей), TypeScript, ESLint, 14 unit-тестов, production build и 5 E2E в Chromium. start.ps1 поднял Vite на 5178, HTTP 200. Скриншоты dark/light/mobile осмотрены.
- Не реализованы DWG/PDF/IFC, реконструкция чертежей в 3D, произвольные BRep/mesh/CSG, сервер Python/IfcOpenShell.
- Известное ограничение: разрез без заливки сечений; нет привязки замера к вершинам; временное состояние просмотра не сохраняется в JSON; импортированный DXF не сохраняется в проект.
- Все требуемые документы актуальны: README, ARCHITECTURE, ROADMAP, DATA_MODEL, DEVELOPMENT, CHANGELOG, AGENTS, PROJECT_STATE и HANDOFF. Скриншоты условного демо: docs/screenshots/dark.png и light.png.

Архитектура: независимая инженерная модель в `src/model.ts`, временное состояние в `src/store.ts`, R3F в `src/Viewer.tsx`, импорт чертежей отдельно в `src/importers.ts`. Координаты в метрах, Y вверх. Расчёты не используют временные положения. Подробности в ARCHITECTURE.md.

GitHub Actions настроен, однако запуск https://github.com/csnicallyou/buildscope/actions/runs/43806221683 не стартовал: GitHub сообщил о неудачных платежах или необходимости увеличить spending limit. Биллинг не менялся. Это не успешный облачный CI; локальные проверки перечислены отдельно.

Предупреждения сборки: JS bundle около 1,36 МБ (gzip 388 КБ), рекомендуется разделение кода; Rollup удаляет две неподходящие PURE-аннотации зависимости Zod. Сборка завершается успешно.

Следующая функциональная задача: JSON v2 со статусами отдельных полей и отсутствующей геометрией, явная миграция v1. Точные команды и файлы в HANDOFF.md. До этого не расширять обещания о PDF/IFC и автоматической реконструкции.

Проверенные сценарии E2E: демо/дерево/свойства, скрытие, разборка, смещение и сброс, неизменность объёма, ведомость (327,258 м³ при условных 36 м), сохранение/загрузка JSON, отклонение невалидного файла без потери текущего проекта, подписи достоверности загруженных данных, CSV/GLB (проверены magic/version/длина GLB), проекции, разрез, тема, изоляция, DXF, выбор поверхности WebGL, расстояние, отсутствие горизонтального переполнения на ширине 390 px.

Не заявляются: строительная пригодность демо, аттестованная точность, поддержка произвольных DWG/PDF/IFC, успешный запуск облачного CI. Наблюдаемых блокирующих ошибок в проверенных локальных сценариях нет; перечисленные ограничения остаются открытыми задачами.
