# Состояние BuildScope

## Актуально: 0.9, 2026-11-16

Переработано рабочее пространство после расширения функций. Единая навигация режимов вынесена над рабочим полем; компактные строки проекта/сборки; дерево и свойства сворачиваются на компьютере. Ведомости, армирование, проверка и источники используют широкое поле. Настройки отображения раскрываются по запросу, генератор демо/импорт находятся в инструментах проекта. На телефоне пять действий снизу (модель, наряд, конструкции, свойства, расчёт), контекстные панели и отдельная компоновка. Обновлены обе темы, таблицы, читаемость свойств, фокус клавиатуры. Основные стили нового интерфейса src/workbench.css; план docs/UI_REDESIGN.md.

Наряд сохраняет интерактивную модель рядом с формой (на телефоне сверху). Выбор в списке подсвечивает соответствующую сборку/часть, реальный клик/касание в WebGL обновляет форму. Есть план сверху, общий вид, переход к частям; строки открываются в той же модели без ухода с вкладки. Из свойств можно перейти к работам по выбранному объекту. Параметры смены свёрнуты; черновик по-прежнему только в памяти страницы.
